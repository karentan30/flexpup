# FlexPup 炫富狗 · 宠物达人种草外联包（0907）

> 目标:找有宠物的达人 → 免费给功能额度 → 晒**自家宠物**的炫富图 → 配文"how I got these cutest pics of my dog" → 把粉丝导流到 flexpup.vercel.app。
> 打法内核:**产品自带病毒素材(真实的狗 vs 生成的富贵狗 = 反差)**。达人不用创作,只需上传1张照片就出片,这是本产品最大的外联优势——**offer 门槛极低,几乎零创作负担**。
> 落地页:https://flexpup.vercel.app

---

## 调研结论(决定怎么谈,别跳过)

数字优先,来自海外真实 seeding/gifting 实践:

- **性价比拐点在 nano/micro**:1K–10K(nano)和 10K–100K(micro)互动率最高、垂类最纯、转化最好。一个 4K 粉、8% 互动、受众重叠的达人,吊打 50K 粉、0.6% 互动的号。**别追大号**——大号有 MCN 过滤 DM、回复率极低、要钱。
- **广撒 gifting > 单个大号**:与其花 $10k 请一个名人,不如把免费额度/礼包发给 50 个 micro,产出更真实的 UGC + 更高转化。这正是我们的模型(我们的"礼包"边际成本≈AI 出图成本,近乎零)。
- **"无发帖义务"的 gifting 转化更高**:直接送、明说"不强制发",反而更多人自愿发,内容更真。给"2–3 个怎么用的建议"当灵感,不当要求。
- **个性化 DM 是命门**:micro 达人对个性化私信回复率远高于模板群发。DM 里必须出现**他最近一条视频/一张宠物照的具体引用**。
- **佣金参考行业档**:nano 15% / micro 12% / mid 8%+flat。我们是 App,先用免费额度+专属码,后期再接分成。
- **合规硬线**:免费产品=材料关联,必须披露。AI 生成内容要**双重披露**(既 #ad 又标 AI-generated)。美国违规罚 $51k–53k/次。这条不能省(见 §6)。

## 2. 外联 DM 模板(英文 · 3 版)

> 铁律:每条 DM 第一句必须引用**他具体某条内容/他家狗的名字**,否则像群发。占位符 `{{...}}` 发前替换。口语、真诚、短。

### 版本 A — 冷启(没互动过,占多数)
```
hey {{name}}! ok {{dogName}} in that {{具体视频, e.g. "beach fetch"}} clip literally made me stop scrolling 😭

quick thing — i build a little app that turns ONE photo of your dog into a "rich dog" luxury photoshoot (private jet, lobster dinner, gold bars lol). it's honestly perfect for {{dogName}}'s whole vibe.

wanna send you free credits, no strings, not asking you to post anything. if you end up loving the pics and wanna share, even better — but zero pressure. can i drop you a code?
```

### 版本 B — 已互动(你先点赞/评论过 3–5 天)
```
hey! been loving {{dogName}}'s content 🐾 that {{具体内容}} one was so good.

made something i think you'll actually enjoy — upload 1 pic of {{dogName}}, get an AI "living like the 1%" photoshoot back (jets, yachts, the works). takes like 30 sec.

giving free access to a few creators whose dogs are basically already celebrities lol. want me to send a code? no obligation to post — just thought {{dogName}} deserved the treatment 😌
```

### 版本 C — 较大达人(接近 10万+,更省话、更给面子、给独家)
```
hi {{name}} — huge fan of what you've built with {{dogName}} 🙌

i run FlexPup — turns one pet photo into a luxury "rich dog" photoshoot. i'd love to set {{dogName}} up with unlimited free access + an exclusive code for your audience (they get a perk, you get commission if you ever want to formalize it).

genuinely no posting requirement to start — send you the pics first, you decide. worth a quick look? 🐶
```

**DM 小抄**
- 发前**先 3 天软触达**(点赞+真评论他的宠物),再私信,回复率翻倍。
- 一次只推一个动作:拿到"想要码"的 yes → 再发码 + link + 晒图脚本。别在第一条塞一堆链接。
- 回复慢的第 4–5 天补一句轻推:`no rush! code's still here if {{dogName}} wants his glow-up 😄`——一次就好,不追第三次。

## 3. 合作 Offer 设计(给什么 / 要什么 / 分档)

**核心 offer(所有档通用):免费无限出图额度 + 专属码,零发帖义务。**
为什么"零义务"反而好——降低戒心,自愿发的内容更真、更多。产品出片只要 30 秒,乐趣即钩子,他们大概率会发。

| 档位 | 粉丝 | 给达人 | 期望(建议非强制) | 归因 |
|---|---|---|---|---|
| **Nano** | 1千–1万 | 免费无限额度 + 专属码 | 1 条图文/短视频 + @flexpup + link in bio | 专属 ref 码 |
| **Micro** | 1万–10万 | 免费无限 + 专属码 + 给粉丝的福利(粉丝用码免费出前 X 张) | 1 条短视频(before→after) + @ + link | 专属码 + UTM |
| **Mid** | 10万+ | 以上全部 + **分成**(粉丝付费下载走他的码,给 12–15% 佣金)+ 定制场景 | 1 条视频 + 置顶评论挂码 | 专属码 + 分成后台 |

**要的东西(优先级)**:①露"真实的狗 vs 生成的富贵狗"对比(产品天然病毒点) ②@flexpup ③link in bio / 置顶评论挂链接。

**★ 我判断转化最高的 offer(见文末结论)**:Micro 档的"**达人自己免费无限 + 专属码让他粉丝也能免费出前 3 张**"——达人不是在推销,是在**给粉丝送福利**,这是最不像广告、最容易发、粉丝最容易点链接的形态。

## 4. 给达人的"晒图脚本"(英文 · 可直接套)

> 发码时一起给达人,让他"照着发"零负担。核心:**before→after 反差 + @flexpup + link in bio**。

### 爆款文案 · 主母版("how I got these")
```
POV: how i got these RIDICULOUS pics of {{dogName}} 😭🐶💰

(show real dog on couch) → (reveal: dog on a private jet / eating lobster / gold bars)

no photographer. no studio. just ONE photo → this.
he thinks he's a CEO now and honestly? he's not wrong 💼

made with @flexpup — link in bio if your dog needs the 1% treatment 🐾
```

### 钩子模板库(前 2 秒,任选)
- `everyone stop — my dog is richer than me now 💰`
- `i turned {{dogName}} into a millionaire with 1 photo and i can't stop`
- `POV: your dog finds out he's the CEO`
- `he doesn't know we're broke 🥲` (自嘲共情,高赞路径)
- `normalize private jets for dogs`
- `show me your dog i'll show you a millionaire` (逼评论/引流)

### before→after 结构(15秒视频脚本)
1. **0–2s 钩子**:真实的狗(趴沙发/啃玩具的平民日常)+ 上面这句钩子文字
2. **2–4s 反差揭示**:切到 AI 生成的富贵图(私人飞机/龙虾大餐/金条),音效 ba-dum
3. **4–10s 连甩 2–3 张**富贵场景,配"he thinks he does this all day"字幕
4. **10–15s CTA**:"1 photo → this. made w/ @flexpup, link in bio 🐾" + 口播/字幕重复一次

### 置顶评论(逼互动 + 挂链接)
```
drop your dog's name below and i'll tell you what CEO energy he's giving 😌
(want yours? link in my bio → use my code {{CODE}})
```

## 5. 追踪归因(每个达人可量化)

**给每人一个专属 ref 码 + UTM**,一码一人才能算清谁带量。

- **码格式**:`达人名缩写`,如 `BELLA`、`MAXPUP`、`OLIVE10`(短、好念、达人愿意口播)
- **落地链接**:`flexpup.vercel.app/?ref=BELLA&utm_source=tiktok&utm_medium=influencer&utm_campaign=seed0907`
  - `ref` = 归因到人(后端记 ref → 落地/注册/付费)
  - `utm_source` 区分 tiktok/instagram,`utm_medium=influencer` 区分种草流量
- **粉丝福利钩子**:`ref` 码 = "用这个码你家狗免费出前 3 张"——既给福利又打点归因,一举两得
- **记录看板(建个 Google Sheet / Notion,列如下)**:

| 达人 | 平台 | 粉丝 | 互动率 | DM状态 | 发码日 | 是否发帖 | 帖链接 | 点击(ref) | 注册 | 付费 |
|---|---|---|---|---|---|---|---|---|---|---|

- **最小可行归因**:即便后端还没接 ref 统计,先用**不同 UTM/短链**(bit.ly 每人一条)看点击数,人工回填付费。别等完美后台再开跑。
- **判断达人质量**:看"点击→注册→付费"漏斗,不是看粉丝数。留下高转化的 3–5 个,复投+升级到分成档。

## 6. 合规(必须执行,别省)

> 美国 FTC:免费产品=材料关联,必须披露;违规 $51k–53k/次。AI 内容要**双重披露**。

- **披露话术(达人帖内,第一句/显著位置,用明确交易词)**:
  - 收了免费额度就发的:帖子**开头**加 `#ad` 或 `#sponsored`(FTC 认这两个词;`#partner`/`#collab`/`#ambassador` **不合格**,视为未披露)。
  - 我们发码时**主动提醒达人**加:`"gifted by @flexpup #ad"` 或 `"@flexpup sent me free credits #sponsored"`。
- **AI 生成标识(双重披露)**:帖内注明内容为 AI 生成,如 `AI-generated with @flexpup` / `#AIart`。TikTok/IG 有 AI 内容标签开关,提醒达人打开。→ 既标 sponsored 又标 AI = FTC 要求的 double disclosure。
- **不承诺虚假效果**:文案不得暗示"真实照片/真在飞机上"。梗要一眼看出是玩笑/AI。品牌梗(Chanel/Hermès 等)**不打真 logo**,用"某法国老牌风"绕开。
- **给达人的一句话合规提醒(随码发)**:
  ```
  quick note so we're both good with the rules: pls pop "#ad" (or "#sponsored") at the START of your caption + mention it's AI-generated (e.g. "AI pics w/ @flexpup"). that's it 🙏
  ```

## 7. 首批 outreach 执行清单(一周批量找 50+ 发 DM)

> 目标:第 1 周锁定 50 个合格达人、发出 30–40 条个性化 DM、发出首批 10–15 个码。**手动冷启,先验 offer 再上工具。**

**Day 1 — 建库 + 素材**
- [ ] 建归因看板(§5 的表)+ 建一页 media kit(1 张图:产品是什么 + before/after 样例 + 落地链接,放公开 Google Drive/一张 flyer)。DM 里甩这一个链接。
- [ ] 准备 3–5 张最强 before→after 样图(从 `~/Desktop/顶美结果/` 选最反差、最好笑的)当"证据"。
- [ ] 建 5–8 个专属码模板 + ref 链接生成规则。

**Day 2–3 — 找 + 筛(目标入库 50)**
- [ ] TikTok 滚 §1 的标签/梗词,每天 25 个候选;IG 同法 25 个。
- [ ] 每个候选查:粉丝 1千–10万?近 3 条互动率 ≥5%?内容玩反差/拟人?→ 合格入库,记下"最近一条可引用的宠物内容"(DM 要用)。
- [ ] **软触达**:给入库达人的宠物内容真点赞 + 真评论(不提产品),养 3 天面熟。

**Day 4–5 — 发 DM(目标 30–40 条)**
- [ ] 按档选模板(A 冷启 / B 已互动 / C 大号),**逐条替换 `{{dogName}}` 和具体内容引用**,绝不群发。
- [ ] 每天发 15–20 条(避免平台判 spam,别一次性百条)。发完记看板 DM 状态。

**Day 6–7 — 转化 + 发码**
- [ ] 对回"想要"的达人:发 专属码 + ref 链接 + §4 晒图脚本 + §6 合规一句话,一次性给全。
- [ ] 追踪:发码后 3 天没动静的,补一条轻推(一次)。
- [ ] 周末复盘看板:回复率 / 发码数 / 首批帖 / ref 点击。留住高转化的,下周升级到分成档 + 复投。

**批量小抄**
- 一次只推一个动作;个性化第一句>一切;别追第三次;先手动验证转化,数据好了再上 Modash/findmecreators 放量。
