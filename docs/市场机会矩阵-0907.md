## 二、优先级排序：该同时做哪几个（前 5）

综合公式：**需求大 × AI竞争小 × 合规安全 × 客单高 × 有护城河/带货延展**。

### 第一梯队（立即做，主攻）

**① 个人品牌照（创业者/博主/自由职业）— 最高毛利**
- 需求中但付费力最强，线下 $450-5000，AI 侧 $19 起 = **价差 25-250 倍**。
- 竞争最小（★☆），真正做"多场景生活方式套图（办公/咖啡厅/演讲台）"垂直定位者极少。
- 合规零风险。护城河 = 一致性 + 自然感（不是网红脸）。
- **理由**：唯一"高客单 × 低竞争 × 零红线"的三优场景，是现金牛。

**② 孕期写真 — 差异化空白 + 情感刚需**
- 需求大（白皮书 2000 家庭），客单 1999-8999，竞争 ★☆。
- **杀手锏**：87% 孕妈把"拍摄安全"列首要，而挺大肚外拍本身危险 → AI 在家出片天然击中安全痛点，是别人没占的定位。
- 合规安全（孕妈本人，非儿童）。守住"真实自然 + 家庭互动"纪实风，别做 P 成假孕妇的猎奇。

**③ 宠物炫富/拟人写真 — 零合规 + 强传播 + 可带货**
- 需求大（宠物 8000 亿·小红书笔记 12 万+·单账号周涨 3w），竞争较多但**未饱和、巨头没重点做**。
- **唯一无肖像权 + 无未成年风险**的场景，社交传播性最强（炫富表情包天然裂变）。
- 变现延展最广：挂画/马克杯/T恤/抱枕带货。护城河 = 内容 + 梗 + 分发（不是技术），适合内容运营驱动增长。

### 第二梯队（同步布局，各有钩子）

**④ 情侣/求婚写真（异地同框）— 高频 + 强裂变**
- 大盘 450 亿，恋爱期即可拍（非一生一次），**异地"从未同框"是刚性真痛点**。
- 双人分享天然裂变，复购强于婚纱。竞争 ★★★ 但异地这个切入点仍热。
- 红线规避：**只做用户本人、绝不碰明星脸、守 AIGC 标识**（明星合照模板已被点名）。

**⑤ 巴厘岛海岛婚纱 —（若要押旅拍，只押这一个）**
- 海岛族群里**需求盘子最大 + 线下最贵**（人均 2.18 万·淡季+140%），AI"9.9 元云海岛"落差感最强，垂直竞争少。
- **前提**：出图必须到婚纱级（水屋反光/婚纱飘动/双人一致性），穿帮即差评。**这是能力门槛项，做不到婚纱级就别开**。
- 马代作为次选补充；夏威夷/欧洲/国内网红地**不单独立项**。

## 三、因未成年人脸红线 → 暂缓 / 单独走法务

以下场景需求真实、甚至极大，但**核心人脸主体是未成年人**，触人脸隐私 + 未成年合规硬雷（妙鸭当年即因人脸隐私被质疑）。**全部暂缓 C 端，由法务单独评估后再定：**

| 场景 | 为何是红线 | 处理建议 |
|------|-----------|---------|
| 全家福（年度合影） | 必含小孩脸 + 家长敏感度极高 + AI 合儿童脸易失真 | 暂缓；若做只做"成人合影"或明确排除儿童 |
| 春节全家福/节日主题 | 全家福必涉未成年 + 被大厂免费碾压双杀 | 暂缓（合规 + 商业双输） |
| 每年生日照 | 儿童生日照是主力需求 | 只做成人自拍，明确避开儿童 |
| 简历照（学生求职） | 高考/学生证大量涉未成年 + 免费化无利润 | 暂缓 C 端；仅 toB 分销（影楼/学校/打印店）成人向 |
| 家庭电子相册 | 含大量儿童人脸 + 红海 + 付费弱 | 暂缓 |

**法务动作清单**：①未成年人脸的采集/存储/生成是否需监护人授权及授权形式；②数据留存与删除机制；③AIGC 标识合规。跑通前，上述场景一律不进 C 端产品线。

## 四、直接回答老板："这个竞争大吗？有很多人做吗？"

**诚实判断：分场景，天差地别。别把"AI 写真"当一个赛道看。**

**1) 拥挤度：通用款已是血海，垂直款还有大片空位。**
- **挤到不能碰的**：证件照、职业头像（PhotoAI 已 $1.6M ARR / Aragon 35万用户）、个人艺术写真（妙鸭爆火后团队 2025.9 已解散，示警纯写真变现难）、古装汉服（开源 SDXL 碾压）、国内网红地旅拍、节日全家福（通义/豆包免费投放碾压）。这些**大厂 + 开源 + 9.9 免费三重挤压，新入者无差异化必死**。
- **有空位的**：个人品牌照、孕期写真、老人尊严照、宠物拟人、异地情侣、垂直海岛婚纱。**这些巨头没重点做、免费模板覆盖不到、且付费意愿真实存在**。

**2) 妙鸭团队解散是最重要的信号。**
它证明了：**"纯通用 AI 写真"是一次性玩具，留存和复购极差，单靠 9.9 覆盖不了生图成本。** 谁再去做通用换脸/换背景，就是接盘。

**3) 我们的差异化在哪（三条护城河，缺一别做）：**
- **垂直定位 + 情感钩子**：不做"通用风格模板"，做"孕妈的安全孕照""创业者的多场景品牌套图""长辈的尊严照""异地情侣的第一张同框"——每个都有别人替代不了的情感理由。
- **复购/裂变机制**：年度订阅（生日/全家福的成长对比）、双人分享（情侣）、社交传播（宠物炫富），把一次性玩具变成留存产品。
- **交付完整度 + 带货延展**：不止出图，做完整交付（妆造+多场景成册）或实物带货（宠物挂画/T恤），价差对标线下 $1000-5000 客单，毛利才立得住。

**一句话给老板**：通用赛道非常挤、别碰；但我们要做的 5 个垂直场景（个人品牌/孕期/宠物/异地情侣/巴厘婚纱）**竞争小、有空位、付费真、且合规安全**。护城河不在技术（大家都能出图），在**垂直情感定位 + 复购裂变 + 交付/带货**。做通用必死，做垂直有戏。

## 五、一句话行动项
- **本周开做**：个人品牌照 + 孕期写真 + 宠物拟人（三个都零合规风险、都能立刻验证付费）。
- **同步布局**：异地情侣（守 AIGC 标识、禁明星脸）、巴厘婚纱（先验能否出到婚纱级再决定）。
- **暂缓走法务**：所有含儿童脸场景（全家福/节日/生日/学生简历照/家庭相册）。
- **不碰**：证件照、职业头像、个人艺术写真、古装、国内网红地、欧洲地标——全是血海。
